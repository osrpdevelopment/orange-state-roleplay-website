# Orange State RolePlay — Coming Soon

A responsive, animated landing page for the Orange State RolePlay PlayStation 5 community.

## Publish with GitHub Pages

1. Create a public GitHub repository (for example `orange-state-roleplay`).
2. Upload `index.html` and `logo.png` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose **main** and **/(root)**, then click **Save**.
6. After deployment, visit `https://YOUR-USERNAME.github.io/orange-state-roleplay/`.

No build tools or dependencies are needed. Fonts use Google Fonts, with local fallbacks.

## Social media
The landing page links to Instagram, YouTube, TikTok, and X. Edit the `href` values in `index.html` to update the profiles.
